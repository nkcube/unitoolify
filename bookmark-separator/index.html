How it works

Chrome and Edge don't natively support adding visual separators to the bookmarks bar. This tool provides a clever workaround!

Simply drag the button above directly onto your bookmarks bar. It will appear as a minimal vertical line (`|`) separating your folders and links.

Note for Edge users: Edge prevents adding duplicate bookmarks. To solve this, every time you click or drag the button, we assign it a unique random ID (UUID) so you can add as many separators as you want!
