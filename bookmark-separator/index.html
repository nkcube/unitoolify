Bookmark Bar Separator

Organize your Chrome/Edge bookmarks bar with visual separators

How it works

Chrome and Edge never shipped a way to put separators on the bookmarks bar, so this page is the workaround: the button above is an ordinary bookmark that happens to render as a thin line. Drag it onto the bar and you are done — no extension, no sync service, nothing to install.

Vertical or horizontal. The vertical separator is a bookmark with an empty title (so it takes up almost no room), while the horizontal one uses a run of box-drawing characters as its title. Pick whichever reads better against your existing bookmarks.

Note for Edge users: Edge refuses to add duplicate bookmarks, so every time you press or drag a button it gets a fresh random fragment in its URL. That is why you can add as many separators as you want without hitting a duplicate wall.

A separator is just a bookmark, so it syncs through your browser account and survives restarts. Two or three lines are usually enough to keep a busy bar organized.

Adding one to the Chrome bookmarks bar, step by step

  1. Show the bar if it is hidden — ⌘+⇧+B on a Mac, Ctrl+Shift+B on Windows and Linux.
  2. Drag the button above onto the bar. Drop it where you want the divider to sit; the insertion marker shows the exact spot.
  3. If the drag does not take, right-click the bar and choose Add page…: name it | and give it any URL. A bookmark called | is the same line.
  4. To move or rename it later, right-click the separator and pick Edit. Clearing the name entirely leaves only the favicon, which is the thinnest result of all.

Nothing about this is a hack inside the browser: a bookmark's label is free text, and a label can be a punctuation mark. That is the whole trick.

Which character makes the best separator?

Anything that renders as a line works, but the choice is not cosmetic — some characters sit differently depending on the font and the platform, and a character that looks tall in a text editor can look like a speck on the toolbar. These are the ones that survive most setups:

  • | — the plain pipe. Narrow, renders everywhere, the usual choice for a vertical divider.
  • │ — box-drawing light vertical (U+2502). Taller than the pipe, closer to a real rule.
  • ┃ — box-drawing heavy vertical. Use it if the light version disappears against your toolbar color.
  • ─── — box-drawing horizontal (U+2500), repeated. The only useful horizontal option, since its strokes join into one continuous line.

Avoid emoji and symbols like • or ★ if you want a divider: they read as decoration, they are wider, and they change shape between platforms.

Firefox, Safari and Edge

Edge is Chromium underneath, so everything above applies unchanged — including the duplicate rule, which is why the button here mints a new URL each time you pick it up.

Firefox hides the bookmarks toolbar by default: right-click the toolbar area, tick Bookmarks Toolbar → Always Show, then drag the button onto it. Firefox accepts the same separator characters, and you can also create one through Library → Bookmarks → Add Bookmark.

Safari calls the bar Favorites: enable it with ⌘+⇧+B under View, and drag the button onto it the same way. Note that Chrome, Edge and Firefox sync bookmarks across devices, while Safari only does so through iCloud — and no mobile browser has a bookmarks bar at all, so separators are a desktop-only idea.

If the separator does not show up

  • The bar is hidden. A separator on an invisible bar looks exactly like no separator. Toggle the bar first.
  • The bookmark is showing a URL. Some browsers fall back to the address when a link has no text. Right-click the bookmark, choose Edit, and type | as the name.
  • Nothing was added at all. Drag from the button itself, not from the page background, and drop it directly on the bar rather than on a folder.
  • Edge says the bookmark already exists. Reload this page and drag again — the URL fragment changes on every press, so the duplicate check passes.

Since a separator carries no state, there is nothing to reset. If one misbehaves, delete it and drag a fresh one.

Removing one

Right-click the separator on your bookmarks bar and choose Delete. There is no state stored anywhere else — this page only generates the bookmark, it does not remember or sync anything you add.

Frequently Asked Questions

How do I add a separator to my Chrome or Edge bookmarks bar?

Open this page, then drag the separator button onto your bookmarks bar. It will appear as a small vertical line (|) between your folders and links. Repeat as many times as you want separators.

Why can't I add multiple separators in Edge?

Edge prevents adding duplicate bookmarks. To work around this, every time you click or drag the separator button it gets a unique random ID (UUID), so you can add as many separators as you like.

Will my separators sync across devices?

Yes. The separator is stored as a normal bookmark, so it syncs through your Chrome or Edge account just like any other bookmark.

Does this work in Firefox or Safari?

The drag-and-drop separator is designed for Chromium-based browsers (Chrome and Edge) which support the bookmarks bar. Firefox's bookmarks bar works similarly, but Safari hides its bookmarks bar by default.

Can I add a bookmark separator without dragging anything?

Yes. Right-click the bookmarks bar and choose "Add page…", then set the name to | and the URL to anything — this page works fine. A bookmark whose name is a single pipe renders as the same vertical line as the drag-and-drop button. You can also edit any existing bookmark and change its name to |.

Which character makes the best bookmark separator?

The plain pipe | is the safest choice: it renders in every font and stays narrow. If you want something taller, │ (U+2502, box-drawing light vertical) or ┃ (U+2503, heavy vertical) look closer to a real rule. For a horizontal divider use a run of ─ (U+2500), because those strokes join into one continuous line — most other dashes leave visible gaps.

Why does my separator show a long URL instead of a line?

When a bookmark has no name, some browsers fall back to displaying the address, so the item becomes a long URL on the bar. Right-click it, choose Edit and type | as the name. In Chrome, clearing the name entirely leaves just the favicon, which is even narrower than a pipe.

Do bookmark separators work on phones and tablets?

No. Mobile browsers have no bookmarks bar to draw on, so separators are a desktop-only idea — Chrome and Edge on Android, and Safari on iOS, show bookmarks in a list instead. If you rely on a synced account, the separators you add on a desktop do still sync to the other desktop browsers on that account.
