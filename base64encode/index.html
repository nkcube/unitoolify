About Base64 Encoding

This is a straightforward Base64 encoder. Paste some text — or upload a file — and you get the Base64 string back. It all runs in your browser, so whatever you type or drop in never gets sent anywhere.

Base64 turns binary data into plain ASCII text using a 64-character alphabet (A-Z, a-z, 0-9, "+" and "/"). That's what makes it the go-to way to embed an image directly in HTML or CSS as a data:image/png;base64,... URI, to get binary attachments through MIME-based email, or to store binary values inside a JSON payload.

In practice you'll reach for it whenever something needs to travel through a text-only channel: an icon inline in CSS, a small file tucked into a JSON document, a blob of bytes inside a database column. Paste or upload, copy, done.

The extra options exist for when plain Base64 isn't quite right. URL-safe mode swaps "+" and "/" for "-" and "_" and drops the trailing "=" padding — what you want if the string is going into a URL, a filename or a JWT. Line chunking breaks the output into 76-character lines, which some older email and MIME setups expect.

Frequently Asked Questions

What is Base64 encoding?

Base64 is an encoding scheme that represents binary data as ASCII text using a 64-character alphabet (A-Z, a-z, 0-9, + and /). It is widely used to transmit binary data over text-only protocols such as email (MIME), and to embed images in CSS and HTML as data URIs.

How do I encode an image or file to Base64?

Click the "Upload a File instead" button, choose any image or binary file, and the tool immediately produces its Base64 string. Use "Download Result" to save the encoded output as a .b64.txt file.

What is URL-safe Base64 (Base64URL)?

Base64URL (RFC 4648) replaces the "+" and "/" characters with "-" and "_" and omits the "=" padding, producing strings that are safe to use in URLs, filenames and query parameters without further encoding.

Is my data safe when I encode it online?

Yes. Everything is processed locally in your browser with JavaScript. Your text and files are never uploaded to any server, so Base64-encoding sensitive data is completely safe.
