# Unitoolify

A premium collection of essential web developer utilities. All tools run completely inside your browser, ensuring fast, private, and secure execution.

## 🚀 Features

- **Client-Side Execution:** No data is sent to any server. Your data remains completely private.
- **Modern Design:** Beautiful UI with responsive, dark-mode styling and glassmorphism.
- **Lightweight & Fast:** Built with vanilla HTML, CSS, and JS for maximum performance.
- **Mobile Friendly:** Fully responsive design that adapts seamlessly to any screen size.

## 🛠️ Available Tools

| Tool | Description |
|---|---|
| **[Base64 Encode](https://www.unitoolify.com/base64encode/)** | Quickly encode your text or binary files into Base64 format safely in your browser. Supports URL-safe mode. |
| **[Base64 Decode](https://www.unitoolify.com/base64decode/)** | Easily decode Base64 strings back to their original text or binary file formats. |
| **[Composerize](https://www.unitoolify.com/composerize/)** | Convert cumbersome `docker run` commands into elegant `docker-compose.yml` files instantly. |
| **[Decomposerize](https://www.unitoolify.com/decomposerize/)** | Reverse engineer your `docker-compose.yml` files back into raw `docker run` commands. |
| **[Prettify JSON](https://www.unitoolify.com/prettify-json/)** | Format, validate, and beautify your raw JSON data into a clean, readable structure. |
| **[Prettify YAML](https://www.unitoolify.com/prettify-yaml/)** | Format, validate, and beautify your YAML configurations with proper indentation. |
| **[JSON to YAML](https://www.unitoolify.com/convert-json-to-yaml/)** | Quickly convert valid JSON data into human-readable YAML format. |
| **[YAML to JSON](https://www.unitoolify.com/convert-yaml-to-json/)** | Instantly convert YAML configurations into strict JSON payloads for APIs and apps. |
| **[UUID Generator](https://www.unitoolify.com/uuid-generator/)** | Instantly generate secure, random v4 or v1 UUIDs in bulk. |
| **[Bookmark Separator](https://www.unitoolify.com/bookmark-separator/)** | Organize your browser bookmarks bar with drag-and-drop vertical and horizontal visual separators. |

## 💻 Tech Stack

- **Core**: HTML5, Vanilla JavaScript
- **Styling**: Vanilla CSS (CSS Variables, Flexbox, CSS Grid)
- **SEO Ready**: Configured with `sitemap.xml` and `robots.txt`
