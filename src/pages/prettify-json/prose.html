About Prettify JSON

Takes minified JSON — the kind that arrives as one long unreadable line — and pretty-prints it with indentation and line breaks. If the JSON is malformed, it tells you where instead of failing silently.

Where it actually saves you time: pasting a curl or webhook response you can't parse, reviewing a config file in a pull request, or hunting for the one wrong comma in a long export. Indentation is your call — 2 spaces, 4 spaces, or tabs — and you can copy or download the result once it looks right.

Everything runs in the browser, which matters if the JSON you're formatting came from an API and contains tokens or personal data you'd rather not send to a random website.
