About Decomposerize

The reverse of Composerize: paste a docker-compose.yml and get the equivalent docker run command(s) back. Useful when you want to test a single container without spinning up compose, or when the tutorial you're following happens to be in the other format.

Each service becomes its own run command with the right flags. It's also a decent way to see what Compose is actually doing under the hood — the raw flags it maps your YAML to.

All in the browser; nothing leaves your machine.

How to use Decomposerize

Paste your docker-compose.yml into the input to generate docker run commands. Copy the command for the service you want to test and review its ports, volumes, and environment variables before running it.

For a service with image: nginx and ports: ["8080:80"], the corresponding port mapping is docker run -p 8080:80 nginx. Generated commands may include additional options from your Compose file.

Compose can coordinate multiple services. Review shared networks, named volumes, and service dependencies separately when running containers with individual commands.
