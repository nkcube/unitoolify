About HTML Encoding

HTML encoding escapes the five characters that have meaning in markup — <, >, &, " and ' — so the browser shows them as literal text instead of interpreting them. That's the whole trick behind displaying code on a page without it rendering.

If your site renders anything users typed — comments, forum posts, chat messages — escaping it is the first thing standing between you and an XSS mess. It's also exactly what code blocks on blogs and docs sites do under the hood.

Runs entirely in your browser; nothing you paste is uploaded anywhere.
