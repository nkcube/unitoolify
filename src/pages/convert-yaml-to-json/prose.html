About YAML to JSON Converter

The other direction: YAML in, JSON out. Most APIs, databases and tools speak JSON, so when a config file is written in YAML but something downstream needs JSON, this is the bridge.

You can get pretty-printed JSON or minified single-line output — handy for stuffing a config into a request body or a single field. It uses the js-yaml library under the hood, so anchors, aliases and multi-line strings get resolved rather than mangled.

All done locally in the browser; the YAML never leaves your machine.
