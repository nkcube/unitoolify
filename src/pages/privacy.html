Short version: what you paste into a tool is processed by JavaScript in your browser and is never uploaded. Analytics is optional, off until you accept it, and never sees your input.

Tool input

Every encoder, formatter, converter and generator on this site runs as client-side JavaScript. Text you type, files you select and Base64 you paste stay in the browser tab: there is no API call, no upload endpoint and no server-side copy. Closing the tab discards the input.

Because of that, the tools keep working when you are offline after the page has loaded, and no result is ever stored on our side.

Analytics (optional)

When you accept, the site loads Google Analytics 4 to count page views and basic interaction events (for example "copy result"). We use it to know which tools are worth maintaining. It records the page URL, referrer, approximate location derived from IP, device and browser type — never the contents of a tool's input or output.

If you decline, the analytics script is never requested. Your choice is stored in localStorage under the key ut-consent; no cookie is set by this site itself. You can change your mind at any time with the "Cookie settings" link in the footer.

Google may process this data outside your country; see Google's privacy policy.

Hosting and server logs

The site is served as static files by Vercel. Like any web host, Vercel processes request metadata (IP address, user agent, timestamp) to deliver pages and protect against abuse. We do not combine those logs with anything else, and we do not sell data.
