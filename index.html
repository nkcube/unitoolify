Encoders / Decoders

Turn data into another representation and back.

🔒
Base64 Encode

Encode text or files to Base64 in your browser. URL-safe mode and MIME line chunking included.

🔓
Base64 Decode

Decode Base64 back to text or binary files. Handles Base64URL automatically, all locally.

🔗
URL Encode

Percent-encode any string for URLs, query strings or form bodies.

🔗
URL Decode

Turn percent-encoded strings back into readable text, tolerantly.

HTML Encode

Escape HTML entities for text or attribute contexts, or encode all non-ASCII.

🌐
HTML Decode

Convert HTML entities back into raw text characters.

YAML Formatter
